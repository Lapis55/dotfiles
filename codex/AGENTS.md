# General

Even if the question is written in English, as a general rule, respond in Japanese.
When requesting approval, ask for confirmation while briefly indicating the content to be confirmed in Japanese.

# Regarding MATLAB Simulink

When performing tasks related to MATLAB or Simulink, be sure to use the Agentic Toolkit skills and MCP server for operations, rather than batch or command-line operations. Run tasks in batch mode only when I explicitly instruct you to do so, such as when I want something to run in the background without stopping the session.

For Simulink, note that a MATLAB session must be launched and the initialization function must be called beforehand. The initialization function has already been added to startup.m, so it will run automatically when MATLAB starts.


# From Time to Time

When repeated failures or recurring stumbling blocks occur, summarize them as appropriate into local skills to accumulate operational knowledge and prevent the same failures from recurring.

When you have been working on the same issue for a while without making progress, it may indicate a fundamental lack of information or that the approach itself is poor. In that case, honestly give up once and ask the user to decide how to proceed.
